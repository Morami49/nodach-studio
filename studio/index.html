                    Private files

                    Raw recordings and photos upload into Studio's file store encrypted in this browser with your compartment passphrase (Q111 B, D-119). The passphrase is never saved: without it nobody, including Studio, can open the files, and if you lose it they can't be recovered. Files over 15 MB, or when uploads aren't available, go in your own storage with a link instead (Q111 A).

                    Develop Studio from Studio
                    
      
                    Look and schema changes take effect the moment you save them, for everyone, and each one is a version you can go back to (D-152). Anything that needs new code becomes a change request: once you approve it, the change-intake job turns it into a GitHub issue for whichever AI or person is building, and the result comes back through tests and a deploy you can see in Runs (D-149, D-153). Nothing here can break the record: Studio only reads these settings, it never rewrites history.
